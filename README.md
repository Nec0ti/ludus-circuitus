# Ludus Circuitus

Ludus Circuitus, başlangıç düzeyindeki öğrenenlerin görsel bloklarla dijital mantık kurmasını, mantıksal sinyalleri izlemesini ve gerçek Verilog karşılığını görmesini amaçlayan açık kaynaklı bir öğrenme projesidir. Ortaokul düzeyinde de anlaşılabilecek bir web deneyimi ve basit quiz/test ile ölçülebilir kazanım hedeflenir.

Site üç bölümden oluşur:

- **Tanıtım:** Projenin amacı, Verilog öğrenirken karşılaşılan güçlük ve yaklaşımımız.
- **Dokümantasyon:** Başlangıç, kullanım, bloklar ve yerel kurulum için Türkçe kılavuz.
- **Devre Atölyesi:** Blueprint dosyalarıyla devre kurma, benzetme, devreyi görme ve üretilen Verilog'u inceleme alanı.

Site Jekyll ile hazırlanıp GitHub Pages'te yayımlanır. Proje kapsamı ve açık kararlar [`notes.md`](notes.md), güncel işler [`backlog.md`](backlog.md), çalışma kuralları [`AGENTS.md`](AGENTS.md) ve [`const.md`](const.md) içindedir.

TÜBİTAK 2204-A kuralları, kaynak haritası ve özgün Verilog örnekleri [`research/`](research/) altında etiketlenmiştir. İnsan katılımcılı öğrenme ölçümü gerekli okul/veli izinleri alınmadan yapılmaz.
